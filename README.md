# ItemKillCommand
MinecraftのPaper/Foliaサーバー用のプラグイン。
`/itemkill`コマンドで、落ちているすべてのアイテムを削除します。
`/kill @e[type=item]`時の、`/kill @e`の誤爆防止に活用できます。
## 追加されるコマンド
`/itemkill`サーバー内のすべてのワールド内のアイテムをkillし、実行者に結果を報告します。
実行にはitemkill.use権限が必要です。(opを持ってる場合は基本的に自動的に付与されます。)
